СКАН — обновление интерфейса 0.2

В архиве три файла для замены: index.html, app.js, style.css.
Это обновление существующего сайта, а не отдельный комплект установки.

1. Распакуйте архив.
2. В репозитории scan_prod откройте Code → Add file → Upload files.
3. Перетащите ТРИ файла: index.html, app.js, style.css. Они должны заменить одноимённые файлы в корне.
4. Нажмите Commit changes.
5. Дождитесь успешной публикации во вкладке Actions.
6. Обновите страницу сайта на телефоне.

config.js, core.js и папку vendor оставьте как есть. Данные и фото на Диске менять не нужно.

До подключения: только «Подключить Яндекс Диск» и «Инструкция».
После подключения: только «Новый» и «Выбыл». Главные экраны занимают высоту окна без прокрутки.
Сканирование, ввод кода и фотографии открываются отдельными экранами.
После сохранения — возврат к двум кнопкам. Сообщения об успехе исчезают автоматически.
Настройки подключения доступны внутри инструкции. Client ID из config.js или ранее введённый ID имеет приоритет; запасной ID — из вашего приложения.
Если вернулись из незавершённой операции на главный экран, нажмите ту же кнопку, чтобы продолжить черновик.

Проверено в браузере: главные экраны, ровно две видимые кнопки, отсутствие прокрутки документа, поступление и возврат, форма фото и возврат к черновику. Синтаксис и соответствие элементов проверены. Функции обмена с Диском и формирования Excel сравнены с вашим работающим исходником — без изменений. Физический iPhone в этой проверке не использовался.
